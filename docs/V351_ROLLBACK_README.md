# v3.5.1 回退包说明

当前回退包基于 Git 中最后一个可复现的稳定节点：v3.4.2，提交 `1322bf3`。仓库没有可复现的 v3.5.0 提交或现成制品，因此不得把不存在的 v3.5.0 当作回退依据。构建时仅应用 `V342_ROLLBACK_PACKAGING_PATCH.diff` 中的 PyInstaller 兼容补丁，未修改旧版业务代码。

该回退包仅用于 v3.5.1 现场故障后的紧急独立启动，不属于“无数据库版”；它可能恢复旧版数据库行为。禁止覆盖 v3.5.1 安装目录、`config.json`、日志、状态目录或任何源文件目录。

回退步骤：

1. 停止 v3.5.1 并确认进程退出。
2. 复制保存 v3.5.1 的 `config.json`、`logs/`、`data/`、`resume_data/`，不要删除。
3. 将回退 ZIP 解压到全新目录，重新计算 ZIP 哈希并核对侧车文件。
4. 先不复制配置启动回退版；确认能打开后，由管理员逐字段人工重配或审核兼容性。
5. 只用非生产测试文件验证一次 SMB/FTP、目标完整性和备份行为。
6. 任一步失败即停止回退版，保留全部文件和日志，恢复 v3.5.1 独立目录。

正式放行前，现场必须实际演练上述步骤并把证据写入 `field_evidence.json`；开发机能够启动不等于现场回退门禁通过。
