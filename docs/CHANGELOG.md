# 版本摘要（精简版）

## v3.5.2 现场验证候选（2026-09-17）
- **手动扫描取消修复**：关闭磁盘清理窗口只请求协作取消并解除界面监听，不再在 GUI 线程同步等待扫描 QThread；SMB/网络盘当前 I/O 返回后由 Worker 自行收尾。
- **扫描结果增量显示**：候选文件发现后按小批次立即送入界面；列表改为 Qt 模型/视图虚拟化，不再固定 1000 行分页，也不再等待全量扫描完成后创建海量 Qt 表格项。
- **容量与取消边界**：扫描统计继续使用 Python 任意精度字节数，支持 100 TB 及以上；跨线程结果传输采用有界批次，避免事件队列堆积导致取消表象卡死。
- **验证状态**：本地自动化与候选包完整性验证通过后，仅作为现场测试包提供；真实 SMB/FTP/FTPS、断网恢复、磁盘压力与 24–72 小时长稳仍必须记录真实证据，正式结论保持 NO-GO。

## v3.5.1-no-database 最终现场候选（2026-09-14）
- **本地实施完成**：路径安全、FTP 临时提交、文件代际状态机、原子 JSON 状态、归档持久化会话内恢复、UNC 后台探测、组合暂停状态、类型化配置、流式安全清理和无数据库生产链路均已接线。
- **权限修复**：默认口令只提示风险，不再强制改密或禁用业务；改密由 `AuthController` 持久化并读回校验，普通配置保存不会回写旧密码快照。
- **自动清理正式开放**：删除恒为 false 的旧冻结门禁；管理员可保存并启用自动清理。自动模式仍只允许回收站，任何失败均保留文件且不会降级为永久删除。
- **清理审计补齐**：手动永久删除要求二次授权和审计可用，并记录 INTENT、OK/FAIL；手动/自动/归档共用 `SafeDeletionPolicy`。
- **自动化结果**：主开发环境 `184 passed, 5 subtests passed`；从锁文件全新安装的独立虚拟环境 `183 passed, 1 skipped, 5 subtests passed`，跳过项为 Windows 符号链接权限；重点生产文件和发布工具 Pyright `0 errors`。
- **可复现构建**：独立环境使用 Python 3.13.5、PyInstaller 6.12.0 构建；候选目录、逐文件清单、ZIP CRC/成员/哈希、运行产物和数据库路径/内嵌模块执行二次校验；隔离 EXE smoke 的 9 项检查全部通过。
- **真实回退物**：删除不存在的 v3.5.0 回退声明；基于最后一个可复现稳定提交 `1322bf3` 生成 v3.4.2 独立回退包，仅应用有记录的 Qt/ICU 打包兼容补丁，5 秒启动验证通过。该回退版本不是无数据库版。
- **现场工具**：补回资源长稳脚本，新增严格的现场证据校验器、默认 NO-GO JSON 模板、逐项手工测试清单和候选/回退包构建验证工具。
- **发布门禁**：当前保持 `NO-GO`。真实 SMB/FTP、最大文件、网络中断、强杀/断电、24--72 小时长稳、逐文件对账、真实回退演练和负责人签署必须在现场完成后才能放行。

- **动态删除模式**：文件遍历与删除模式解耦；自动清理在删除每个文件前重新读取当前“移入回收站”配置，并按实际模式记录删除审计。
- **失效配置收敛**：删除无运行分支的 `monitor_mode`、`enable_resume`、`auto_delete_keep_days`；旧配置读取兼容，并在下次成功保存时自动移除这些键。

## v3.5.1 (2026-08-10)
- **上传前延迟可配置**：新增 `file_upload_delay_seconds` 配置项；扫描到待上传文件后按配置等待再开始上传，默认 `1.5` 秒，设为 `0` 可关闭。
- **配置链路补齐**：延迟参数贯通配置模型、上传任务、Service 和 Worker，保存配置时不会丢失。
- **回归测试**：完整测试集共 `94 passed, 5 subtests passed`。

## v3.5.0 (2026-08-07)
- **MVC 架构重构**：生产入口改为统一组合根，界面、Controller、Service、Repository、Model 和 Worker 职责分离，上传、清理、FTP、权限、配置及运行时状态通过明确边界协作。
- **托盘退出可靠性修复**：退出请求统一交由 `LifecycleController` 编排，等待上传和清理 Worker 协作式停止后再退出 Qt 主事件循环。
- **退出确认与安全回退**：仅在收到 `aboutToQuit` 后释放托盘和单例资源；`QApplication.quit()` 未生效时安全重试 `exit(0)`，仍未确认则取消退出并恢复界面，避免半退出残留进程。
- **线程关闭安全补强**：上传和清理线程等待均设置超时，不再使用 `QThread.terminate()` 强制撕毁线程。
- **单实例通知补强**：已有实例收到 WAKEUP 后激活主窗口，并显示“程序已在运行／实例已激活”托盘通知。
- **磁盘清理界面修复**：基础路径未勾选时统一显示灰色，勾选后恢复亮色。
- **回归测试**：生命周期、上传、清理、单实例、权限及完整测试集共 `93 passed, 5 subtests passed`。

## v3.4.2 (2026-08-06)
- **自动清理策略统一**：达到触发阈值后不再使用保留天数过滤，按监测文件夹组内全部配置目录及子目录的文件修改时间全局最旧优先清理，并使用规范化完整路径确定同时间顺序。
- **磁盘与删除安全**：跨磁盘配置在保存和运行时均被阻止；每次删除后读取实际磁盘占用率，达到目标阈值立即停止；扫描和删除失败共用 20 次上限，回收站未释放空间时停止本轮。
- **独立清理审计**：新增 `cleanup_YYYY-MM-DD.log`，记录每轮开始、扫描失败、删除成功、删除失败和结束状态；审计无法持久化时停止继续删除。
- **退出与并发修复**：退出时先取消并等待自动清理，再刷新日志线程池；任务提交失败会恢复运行状态，每轮清理固定使用启动时的配置快照。
- **开机自启自愈**：支持中文和空格路径、旧 EXE 路径修复与版本防降级；源码模式同时校验 Python 解释器和 `src/main.py`。
- **回归测试**：覆盖全局排序、保留天数失效、跨盘阻止、失败上限、回收站保护、审计故障、退出取消、配置快照及启动项修复。

## v3.4.1 (2026-06-11)
- **低分辨率 UI 适配**：主窗口按当前屏幕可用分辨率计算初始尺寸、最小尺寸、字体、间距、卡片高度和状态芯片列数；1024x768 最大化时不再由 1200/1250px 固定宽度制造横向滚动。
- **弹窗尺寸裁剪**：登录、修改密码、重复文件确认和磁盘清理窗口按屏幕上限裁剪；磁盘清理不再强制 1100/1300px 宽度，适配现场小屏电脑。
- **响应式回归测试**：新增 1024x768、1920x1080 尺寸计算和 offscreen UI smoke 测试，防止后续恢复固定大尺寸。

## v3.4.0 (2026-06-11)
- **FTP 服务器独立运行**：内置 FTP 服务器可由管理员单独启动/停止，不再依赖上传任务；server-only 场景不要求源文件夹和目标文件夹。
- **FTP 服务器事件日志**：外部客户端连接、登录成功/失败、断开、上传成功、上传未完成、启动/停止等事件写入 `logs/ftp_server_YYYY-MM-DD.txt`，关键事件同步显示在运行日志。
- **生命周期与权限收敛**：独立启动的 FTP 服务器不会被“停止上传任务”误停，退出软件时统一关闭；服务器运行中锁定配置，仅管理员可控制。

## v3.3.3 (2026-05-20)
- **FTP 服务器增强**：内置 FTP 服务器（基于 pyftpdlib）支持 FTPS/TLS 加密连接，可配置证书文件（cert/key）；被动模式端口范围可在 UI 中自由设定（`passive_ports_start/end`）；新增最大连接数及单 IP 连接限制。
- **FTP 协议管理器四模式**：`FTPProtocolManager` 支持 `none / server / client / both`（混合）四种工作模式，可同时运行服务器与多个客户端，模式切换无需重启应用。
- **FTP 客户端上传**：`FTPClientUploader` 提供完整的连接/断开/单文件上传/文件夹递归上传能力，支持断线重连与上传重试。
- **服务器状态监控**：`FTPServerManager.get_status()` 实时返回运行状态、当前连接数和监听地址，主窗口状态卡片同步展示。

## v3.3.2 (2026-05-20)
- **密码加密存储**：FTP 密码改用 Windows DPAPI（`protect_secret`/`unprotect_secret`）加密后写入 config.json，明文不再落盘；`guest` 角色禁止修改密码，仅 `admin` 可操作。
- **磁盘不足紧急清理**：Worker 检测到磁盘空间不足时发出 `DISK_LOW` 事件，由主窗口统一清理引擎接管处理；Worker 任务结束后自动恢复定时清理。
- **文件列表交互增强**：`FileListTable` 新增 `check_state_changed` 信号，复选框勾选变化时实时刷新删除按钮启用状态；删除模式（回收站/永久删除）显式集成到下拉按钮。
- **配置变更检测补齐**：路径输入框手动编辑、Spin 控件数值变更均标记配置已修改，避免遗漏保存提示。
- **测试覆盖扩充**：新增 `test_auto_cleanup_edge_cases`、`test_auto_cleanup_execution`、`test_auto_cleanup_selection`、`test_config_manager`、`test_disk_cleanup_dialog`、`test_secret_utils` 共 6 个测试模块。

## v3.2.0 (2026-04-13)
- 文件清理界面升级为可勾选表格，支持排序、搜索、右键操作、扫描进度、删除前摘要和更清晰的交互反馈。
- 自动清理配置补齐到界面层，支持保留天数、格式过滤、回收站删除模式，并与主窗口配置保存/回填链路统一。
- 自动清理执行链路调整为由主窗口统一调度，Worker 仅负责告警；紧急清理模式会透传到统一清理任务。
- 权限与按钮联动收敛：`guest` 不能执行清理和配置保存，运行中禁止修改配置，删除按钮只跟随勾选文件启用。
- 配置加载守卫补齐，避免启动时把配置回填误记为“用户手动修改”。
- 打包链路对齐版本号，PyInstaller 固定使用 `PySide6`，并补充 `Send2Trash` 依赖，保证回收站功能在打包版中可用。
